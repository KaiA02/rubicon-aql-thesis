# RUBICON – Implementation

Flask web application implementing the AQL query interface.

## Setup

1. Install dependencies: `pip install -r requirements.txt`
2. Create `Configurations/config.ini` with your OpenAI API key
3. For Gmail access, add `client_secret.json` to `Configurations/`
4. Run the app: `python app.py`

API keys and credentials are not included in this repository.
